# Customer Sales Pipeline

A Python and Pandas project that demonstrates a real-world-style
data processing pipeline using customer, order, and payment data.

## Pipeline

Raw Excel Data
      ↓
Data Cleaning
      ↓
Data Validation
      ↓
Data Analysis
      ↓
Excel Reports

## Technologies

- Python
- Pandas
- OpenPyXL

## Features

- Customer data cleaning
- Order data cleaning
- Payment data cleaning
- Duplicate detection
- Missing-value validation
- Data-quality validation
- Customer sales analysis
- Category analysis
- Payment analysis
- Automated Excel report generation
